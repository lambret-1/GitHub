# Actions 管理页面目录

本目录存放 GitHub Actions 管理相关的视图文件，包括工作流列表、运行记录、运行详情和作业日志。

## 文件说明

### ActionsListView.swift
**Actions 主视图**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `owner` | 仓库所有者 | GitHub 用户名或组织名 |
| `repo` | 仓库名称 | GitHub 仓库名称 |
| `selectedTab` | 选中标签 | 当前选中的标签（运行记录/工作流） |
| `workflows` | 工作流列表 | 仓库的 GitHub Actions 工作流数组 |
| `runs` | 运行记录列表 | 仓库的工作流运行记录数组 |
| `isLoadingWorkflows` | 加载工作流中 | 工作流列表加载中的状态标记 |
| `isLoadingRuns` | 加载运行记录中 | 运行记录列表加载中的状态标记 |
| `errorMessage` | 错误信息 | 加载失败时的错误提示文本 |
| `currentPage` | 当前页码 | 分页加载的当前页码 |
| `hasMoreRuns` | 有更多运行记录 | 是否还有更多运行记录可加载 |
| `showTriggerAlert` | 显示触发确认 | 控制触发工作流确认弹窗的显示 |
| `selectedWorkflow` | 选中的工作流 | 当前选中要触发的工作流 |

**标签页：**
- 运行记录：显示所有工作流的运行记录
- 工作流：显示仓库的所有工作流列表

**运行记录列表项（WorkflowRunRow）：**
- 状态图标（成功/失败/进行中/排队中）
- 工作流名称和运行编号
- 分支名和提交短哈希
- 触发事件标签和创建时间
- 状态文本标签（带背景色）

**工作流列表项（WorkflowRow）：**
- 工作流图标（闪电图标）
- 工作流名称和文件名
- 工作流状态（启用/禁用）
- 触发按钮（绿色播放图标）

**功能操作：**
- 点击运行记录：跳转到运行详情页面
- 点击触发按钮：弹出确认弹窗，确认后触发工作流运行
- 下拉刷新：重新加载当前标签页内容
- 分页加载：滚动到底部自动加载更多运行记录

**触发工作流：**
- 使用 workflow_dispatch 事件触发
- 默认触发 main 分支
- 触发成功后自动切换到运行记录标签页
- 触发成功后自动刷新运行记录列表

### WorkflowRunDetailView.swift
**运行详情视图**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `owner` | 仓库所有者 | GitHub 用户名或组织名 |
| `repo` | 仓库名称 | GitHub 仓库名称 |
| `run` | 运行信息 | 当前查看的工作流运行数据模型 |
| `jobs` | 作业列表 | 该运行的作业数组 |
| `isLoadingJobs` | 加载作业中 | 作业列表加载中的状态标记 |
| `errorMessage` | 错误信息 | 加载失败时的错误提示文本 |
| `showCancelAlert` | 显示取消确认 | 控制取消运行确认弹窗的显示 |
| `showRerunAlert` | 显示重新运行确认 | 控制重新运行确认弹窗的显示 |
| `isRefreshing` | 刷新中 | 下拉刷新进行中的状态标记 |

**页面结构：**
1. 运行状态概览 Section
   - 大状态图标
   - 工作流名称和运行编号
   - 状态标签（带背景色）

2. 运行详情 Section
   - 分支名
   - 提交短哈希
   - 触发事件
   - 创建时间
   - 触发者（如有）
   - 提交信息（如有）

3. 操作按钮 Section（根据状态显示）
   - 进行中/排队中：显示"取消运行"按钮（红色）
   - 已完成：显示"重新运行"按钮（蓝色）

4. 作业列表 Section
   - 作业数量标题
   - 每个作业项显示：状态图标、作业名称、运行时长、Runner 名称、状态文本
   - 点击作业跳转到作业日志页面

**作业行（JobRow）：**
- 状态图标
- 作业名称
- 运行时长和 Runner 名称
- 状态文本

**功能操作：**
- 点击作业：跳转到作业日志页面
- 点击取消运行：弹出确认弹窗，确认后取消运行
- 点击重新运行：弹出确认弹窗，确认后重新运行
- 下拉刷新：同时刷新运行状态和作业列表

**取消运行：**
- 仅在运行状态为 in_progress 或 queued 时可用
- 取消前二次确认
- 取消成功后自动刷新运行状态和作业列表

**重新运行：**
- 仅在运行状态为 completed 时可用
- 重新运行前二次确认
- 重新运行成功后自动刷新运行状态和作业列表

### JobLogView.swift
**作业日志视图**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `owner` | 仓库所有者 | GitHub 用户名或组织名 |
| `repo` | 仓库名称 | GitHub 仓库名称 |
| `job` | 作业信息 | 当前查看的作业数据模型 |
| `logs` | 日志内容 | 作业的完整日志文本 |
| `isLoading` | 加载中 | 日志加载中的状态标记 |
| `errorMessage` | 错误信息 | 加载失败时的错误提示文本 |
| `showSteps` | 显示步骤 | 控制步骤列表的展开/折叠 |

**页面结构：**
1. 作业信息头部
   - 状态图标
   - 作业名称
   - 状态文本

2. 步骤列表（可折叠）
   - 横向滚动展示每个步骤
   - 每个步骤显示：状态图标、步骤名称、运行时长
   - 点击标题可展开/折叠

3. 日志内容区域
   - 等宽字体显示
   - 支持文本选择
   - 可滚动查看完整日志
   - 加载中显示进度指示器
   - 加载失败显示错误提示和重试按钮
   - 无日志时显示空状态

**步骤项：**
- 状态图标（成功/失败/进行中/等待中/已跳过）
- 步骤名称（固定宽度，单行显示）
- 运行时长

**日志加载：**
- 页面出现时自动加载日志
- 使用 GitHub API 获取作业日志
- 日志为纯文本格式
- 支持错误重试

**日志显示优化：**
- 使用等宽字体（monospaced）
- 字体大小 10pt
- 左对齐显示
- 支持长按选择和复制文本
- 背景色使用系统背景色
