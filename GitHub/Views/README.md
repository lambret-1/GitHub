# 视图层目录

本目录存放应用的所有 SwiftUI 视图文件，按功能模块划分为多个子目录。

## 子目录说明

### Login/
**登录页面** - Token 登录界面，支持暗黑风格动画特效

### RepoList/
**仓库列表页面** - 显示用户仓库列表和星标仓库列表，支持搜索、筛选、排序、左滑取消星标、重按菜单

### FileBrowser/
**文件浏览器页面** - 仓库文件浏览、上传下载、创建删除、分支管理、星标/Fork、README展示等核心功能

### CodeEditor/
**代码编辑器页面** - 高性能代码编辑器，语法高亮，行号显示，查找替换，双指缩放，大文件流畅打开

### Search/
**搜索页面** - 仓库搜索和用户搜索，支持高级筛选，搜索结果跳转

### Profile/
**个人中心页面** - 用户信息、账号管理、暗黑模式切换（双击头像）、检查更新

### About/
**关于页面** - 应用信息、版本检查、镜像加速设置

### Actions/
**Actions 管理页面** - GitHub Actions 工作流和运行记录管理，支持实时日志流、工作流编辑器、运行详情

### Commits/
**提交记录模块** - 仓库提交历史列表、提交详情、文件Diff对比，支持大文件流畅渲染、双指缩放

### Issues/
**Issues 管理页面** - 仓库Issues列表和详情，支持状态筛选、新建Issue

### PullRequests/
**Pull Requests 管理页面** - 仓库PR列表和详情，支持状态筛选、新建PR

### Settings/
**仓库设置页面** - 仓库设置和统计信息展示

### Components/
**通用组件** - 可复用的UI组件（搜索栏、缓存图片视图等）

### Shared/
**共享组件** - 跨模块共享的视图组件

## 视图层架构

### MVVM 架构

```
Views (视图)
    ↓ 观察
ObservableObject (视图模型/状态)
    ↓ 调用
Core/Utils (工具层)
    ↓ 调用
Core/Network (网络层)
```

### 状态管理

- `@State`：视图内部私有状态
- `@Binding`：父子视图双向绑定
- `@ObservedObject`：观察外部对象状态
- `@EnvironmentObject`：环境对象全局状态
- `@AppStorage`：UserDefaults 持久化状态

## 视图规范

1. 所有视图必须使用 SwiftUI 声明式语法
2. 视图必须 100% 中文汉化，所有界面文案使用中文
3. 复杂视图必须拆分为子视图，避免 body 表达式过于复杂
4. 网络请求必须在视图出现时发起，完成后在主线程更新 UI
5. 加载状态、错误状态、空状态必须有对应的 UI 展示
6. 列表必须支持下拉刷新
7. 分页加载必须实现加载更多和无更多数据状态
8. 新增视图时必须更新对应子目录的 README 说明
9. 所有视图必须适配深色模式
10. 所有视图必须适配安全区、横竖屏与动态字体
