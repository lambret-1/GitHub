# 个人中心页面目录

本目录存放个人中心相关的视图文件，包括用户信息展示、账号管理、添加账号等。

## 文件说明

### ProfileView.swift
**个人中心主视图**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `user` | 当前用户 | 当前登录的用户信息 |
| `isDarkMode` | 暗黑模式 | 应用是否处于暗黑模式 |
| `showAccountManager` | 显示账号管理 | 控制账号管理页面的显示 |
| `showAbout` | 显示关于 | 控制关于页面的显示 |
| `showCheckUpdate` | 显示检查更新 | 控制检查更新弹窗的显示 |
| `showGitHubProfile` | 显示 GitHub 主页 | 控制在浏览器中打开 GitHub 主页 |

**页面元素：**
- 用户头像（双击切换暗黑模式）
- 用户名和显示名称
- 用户简介（bio）
- 用户统计（仓库数、关注者数、关注数）
- 功能列表：
  - 账号管理（尾部 > 符号）
  - 检查更新（尾部 > 符号）
  - GitHub 查看主页（尾部 > 符号）
  - 关于（尾部 > 符号）

**暗黑模式切换：**
- 我的 > 头像双击切换
- 状态持久化到 UserDefaults
- 应用启动时恢复状态

**账号切换：**
- 切换账号后自动刷新仓库列表
- 切换账号后自动刷新个人中心
- 头像图标缓存到本地

### AccountManagerView.swift
**账号管理视图**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `accounts` | 账号列表 | 所有已添加的账号数组 |
| `currentAccount` | 当前账号 | 当前选中的账号 |
| `showAddAccount` | 显示添加账号 | 控制添加账号页面的显示 |

**页面元素：**
- 账号列表（每个账号显示：头像、用户名、当前账号标记）
- 添加账号按钮（导航栏右侧）
- 左滑删除账号

**账号操作：**
- 点击账号：切换到该账号
- 左滑账号：删除该账号
- 点击添加按钮：跳转到添加账号页面

**账号切换后处理：**
- 更新 Token 到 Keychain
- 更新当前用户信息
- 自动刷新仓库列表和个人中心
- 弹出提示"已切换到账号 XXX"

### AddAccountView.swift
**添加账号视图**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `token` | Token 输入 | 用户输入的 GitHub Personal Access Token |
| `showToken` | 显示 Token | 控制 Token 输入框是否明文显示 |
| `isLoading` | 加载状态 | 验证 Token 进行中的状态标记 |
| `errorMessage` | 错误信息 | Token 验证失败时的错误提示 |

**页面元素：**
- Token 输入框（支持显示/隐藏切换、剪贴板粘贴）
- 创建按钮（确认添加账号）
- 取消按钮
- 错误提示区域

**添加账号流程：**
1. 用户输入 Token
2. 点击创建按钮
3. 调用 GitHubAPI.getUserInfo() 验证 Token
4. 验证成功后保存账号到本地存储
5. 自动切换到新账号
6. 关闭添加账号页面

**输入框优化：**
- 支持第三方输入法切换
- 支持剪贴板粘贴
- Token 输入框默认密文显示
- 支持一键显示/隐藏 Token
- 创建按钮和取消按钮同时存在（避免只有取消按钮）
