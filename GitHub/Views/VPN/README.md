# VPN 视图模块

## 模块概述

本目录包含 VPN 功能的 UI 界面代码，负责展示 VPN 连接状态、节点列表、节点管理等用户界面。

## 文件说明

| 文件名 | 用途 | 核心功能 |
|--------|------|----------|
| `VPNMainView.swift` | VPN 主页面 | 显示 VPN 连接状态卡片、节点列表、连接/断开控制、添加节点（手动/剪贴板导入）、节点管理（编辑/删除/批量操作） |

## VPNMainView 界面结构

### 1. 连接状态卡片

**位置：** 页面顶部

**包含元素：**
- 状态图标（根据连接状态变化颜色和图标）
- 状态文字（已断开/连接中/已连接/断开中）
- 当前选中节点名称
- 连接/断开按钮

**状态颜色：**
- 灰色：已断开/配置无效
- 橙色：连接中/重新连接中
- 黄色：断开中
- 绿色：已连接

### 2. 节点列表

**位置：** 连接状态卡片下方

**每行包含：**
- 协议图标（圆形背景，显示协议名称前两个字母）
- 节点备注名称
- 当前选中标记（绿色勾选图标）
- 服务器地址（地址:端口）
- 延迟显示（颜色标识：绿色<100ms，黄色100-300ms，红色>300ms）
- 右侧箭头（非编辑模式）

**交互功能：**
- 点击节点：选择该节点为当前连接节点
- 长按节点：弹出上下文菜单（使用此节点/编辑节点/测速/删除节点）
- 左滑节点：删除节点
- 编辑模式：多选节点，批量删除

### 3. 导航栏菜单

**位置：** 页面右上角 + 号

**菜单项：**
- 手动添加节点（第一期占位，后续实现完整表单）
- 从剪贴板导入（自动识别 VMess/VLESS 链接）
- 管理节点（进入编辑模式，支持批量删除）

### 4. 空状态视图

**显示条件：** 节点列表为空时

**包含元素：**
- 地球图标
- "还没有添加节点" 文字
- 操作说明文字
- "添加节点" 按钮

### 5. 编辑模式底部操作栏

**显示条件：** 编辑模式且有选中节点时

**包含元素：**
- 全不选按钮
- 已选数量显示
- 删除按钮（红色）

## 尺寸参数说明

### 连接状态卡片

| 参数 | 值 | 说明 |
|------|-----|------|
| 卡片内边距 | 16pt | 卡片内容与边缘的距离 |
| 卡片圆角 | 12pt | 卡片四个角的圆润程度 |
| 状态图标背景 | 48x48pt | 状态图标圆形背景大小 |
| 状态图标字体 | 24pt | 状态图标大小 |
| 连接按钮垂直内边距 | 12pt | 连接按钮的高度 |
| 连接按钮圆角 | 10pt | 连接按钮四个角的圆润程度 |

### 节点行

| 参数 | 值 | 说明 |
|------|-----|------|
| 行内边距 | 上下8pt，左右16pt | 节点行内容与列表边缘的距离 |
| 行垂直内边距 | 8pt | 节点行内容上下的间距 |
| 协议图标背景 | 40x40pt | 协议图标圆形背景大小 |
| 协议图标字体 | 10pt | 协议名称文字大小 |

### 空状态视图

| 参数 | 值 | 说明 |
|------|-----|------|
| 图标顶部间距 | 60pt | 空状态图标与上方的距离 |
| 描述文字水平内边距 | 40pt | 描述文字左右的边距 |
| 添加按钮水平内边距 | 24pt | 按钮左右内边距 |
| 添加按钮垂直内边距 | 10pt | 按钮上下内边距 |
| 添加按钮圆角 | 8pt | 按钮圆角半径 |

## 数据流

```
用户操作 → VPNMainView → VPNManager（单例）
                          ↓
                    节点持久化（Documents/vpn_nodes.json）
                    App Group 共享数据（供 VPN 扩展读取）
                    NEVPNManager（系统 VPN 配置）
                          ↓
                    VPNPacketTunnel（扩展进程）
```

## 第一期功能限制

1. **手动添加节点**：第一期仅提供入口，完整的添加节点表单将在后续期实现
2. **编辑节点**：第一期仅提供入口，编辑功能将在后续期实现
3. **节点测速**：第一期仅提供入口，测速功能将在后续期实现
4. **VPN 代理**：第一期 VPN 隧道启动后数据包直接转发（不做真正的协议代理），VLESS/VMess 协议实现将在后续期完成
5. **节点分组**：数据模型已支持分组，UI 分组展示将在后续期实现

## 注意事项

1. **VPN 权限**：首次使用需要请求系统 VPN 权限，用户必须允许才能使用
2. **节点选择**：必须先选择一个节点才能连接 VPN，未选择节点时连接按钮禁用
3. **剪贴板导入**：支持批量导入（每行一个节点链接），失败的行会被跳过
4. **删除确认**：删除单个节点时会弹出确认对话框，防止误删
5. **深色模式**：所有颜色使用系统语义颜色，自动适配深色模式
