# 仓库列表页面目录

本目录存放仓库列表相关的视图文件。

## 文件说明

### RepoListView.swift
**仓库列表视图**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `repos` | 仓库列表 | 当前用户的仓库数组 |
| `isLoading` | 加载状态 | 仓库列表加载中的状态标记 |
| `errorMessage` | 错误信息 | 加载失败时的错误提示文本 |
| `currentPage` | 当前页码 | 分页加载的当前页码 |
| `hasMoreRepos` | 有更多仓库 | 是否还有更多仓库可加载 |
| `showSearch` | 显示搜索 | 控制搜索页面的显示 |
| `selectedBranch` | 选中分支 | 当前选中的分支名 |

**页面元素：**
- 导航栏标题："仓库"
- 搜索按钮（导航栏右侧）
- 仓库列表（支持下拉刷新、分页加载）
- 每个仓库项显示：仓库名、描述、主要语言、Star 数、Fork 数、更新时间

**仓库项点击：**
- 跳转到文件浏览器页面（FileBrowserView）
- 传递仓库信息和默认分支

**搜索功能：**
- 点击搜索按钮跳转到搜索页面
- 支持仓库搜索和用户搜索
- 支持高级筛选

**下拉刷新：**
- 重新加载第一页仓库列表
- 重置分页状态
