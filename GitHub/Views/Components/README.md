# 通用组件目录

本目录存放可复用的 UI 组件文件。

## 文件说明

### CachedImageView.swift
**带缓存的图片视图组件**

**功能参数说明：**

| 参数/属性 | 中文释义 | 说明 |
|-----------|---------|------|
| `imageURL` | 图片 URL | 要加载的图片的 URL 地址 |
| `placeholder` | 占位图 | 图片加载完成前显示的占位图片 |
| `contentMode` | 内容模式 | 图片的内容填充模式（fill/fit） |
| `cornerRadius` | 圆角半径 | 图片的圆角半径 |
| `isLoaded` | 加载完成 | 图片是否加载完成的状态标记 |
| `currentImage` | 当前图片 | 当前显示的图片（可选） |

**缓存机制：**
- 内存缓存：使用 ImageCache 内存缓存，快速访问
- 磁盘缓存：使用 ImageCache 磁盘缓存，持久化存储
- 缓存有效期：1 天（24 小时）
- 缓存键：使用图片 URL 的 MD5 哈希
- 缓存未命中时从网络下载
- 下载完成后自动存入内存和磁盘缓存

**使用场景：**
- 用户头像显示
- 仓库所有者头像
- 任何需要网络加载图片的地方

**性能优化：**
- 图片加载在后台线程执行
- 加载完成后在主线程更新 UI
- 支持占位图显示
- 支持失败重试
- 避免重复加载相同 URL 的图片

**头像缓存优化：**
- 我的 > 头像图标缓存到本地
- 账号切换后头像立即显示（从缓存读取）
- 避免每次切换账号都重新下载头像
