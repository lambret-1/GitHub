# 资源文件目录

本目录存放应用的所有资源文件，包括图标、颜色、图片等。

## 子目录说明

### AppIcon.appiconset/
**应用图标资源集**

**文件说明：**

| 文件名 | 中文释义 | 说明 |
|--------|---------|------|
| `icon-1024.png` | 1024x1024 应用图标 | 极简黑白风格（章鱼猫+代码符号），App Store 图标 |
| `Contents.json` | 资源集配置文件 | 定义各尺寸图标的映射关系 |

**图标设计说明：**
- 风格：极简黑白
- 元素：章鱼猫剪影 + 代码符号
- 背景：纯黑
- 前景：白色

---

### AppIconImage.imageset/
**应用图标普通图片资源集**

**文件说明：**

| 文件名 | 中文释义 | 说明 |
|--------|---------|------|
| `icon-1024.png` | 1024x1024 图标图片 | 用于登录页面和关于页面显示的应用图标 |
| `Contents.json` | 资源集配置文件 | 定义图片的缩放因子（@1x, @2x, @3x） |

**使用场景：**
- 登录页面顶部图标
- 关于页面应用图标
- 其他需要显示应用图标的地方

---

### AccentColor.colorset/
**强调色资源集**

**文件说明：**

| 文件名 | 中文释义 | 说明 |
|--------|---------|------|
| `Contents.json` | 颜色配置文件 | 定义应用的全局强调色 |

**颜色说明：**
- 浅色模式：系统蓝色
- 深色模式：系统蓝色

---

## 资源管理规范

1. 所有图片资源必须使用 PNG 格式
2. 图标尺寸必须包含 1024x1024 版本
3. 资源命名使用小写字母和连字符
4. 新增资源时必须更新本 README 说明
5. 禁止将大尺寸图片直接放入代码中，统一使用资源集管理
