# GitHub iOS 中文第三方客户端

一个功能完整的 GitHub iOS 中文客户端，支持 Token 安全登录，可随时随地查看、编辑和管理代码。

## 功能特性

### 🔐 安全登录与账号管理
- Personal Access Token 一键登录
- Token 存储在系统 Keychain 中，安全可靠
- 支持自动登录，无需重复输入
- 多账号管理切换，支持添加多个 GitHub 账号
- Token 失效自动跳转登录页面

### 📁 仓库管理
- 查看所有公开和私有仓库
- 支持仓库搜索和筛选（全部/我的/私有/公开）
- 显示仓库语言、Star、Fork、更新时间等信息
- 下拉刷新最新仓库列表
- 星标列表查看，点击跳转到对应仓库
- 新建仓库（支持公开/私有）
- 重命名仓库、修改仓库描述
- 切换仓库公开/私有状态
- 删除仓库（二次确认）
- 重按仓库菜单（重命名、删除、公开/私有切换）

### 👥 别人仓库访问
- 完整复刻自己仓库的布局到别人仓库
- 权限感知引擎：自己仓库 vs 别人仓库显示不同菜单
- 别人仓库菜单：添加星标、Fork仓库、复制仓库地址
- Fork流程闭环：检测Fork状态、Fork引导、二次确认
- 星标状态实时检测和切换

### 📂 文件浏览
- 树形目录结构浏览仓库文件
- 支持多级目录导航（孙目录→子目录→父目录）
- 显示文件大小、类型图标、最后编辑时间
- 时间显示格式：x分钟前、x小时前、x天前、x年前
- 支持切换不同分支
- 路径导航栏（可跟随屏幕滑动）
- 下拉刷新（识别区在上半屏）
- README展示（支持所有子文件夹，Markdown原文渲染）
- 仓库头部信息（Watch/Fork/Star、描述、Topics、LICENSE、仓库大小）
- 分支栏（分支选择、三个点菜单）
- 文件图标完整适配

### ✏️ 代码编辑与查看
- 在线查看代码文件，支持行号显示
- 行号列宽自适应宽度
- GitHub风格语法高亮（函数、关键字颜色正确）
- 代码字体大小可调节（双指放大缩小）
- 支持编辑修改文件内容
- 自定义提交信息，一键提交到 GitHub
- 支持复制代码内容
- 代码搜索功能（仓库内代码搜索）
- 选中文字查找（菜单中🔍查找）
- 查找上一个/下一个（位置互换，浅背景色）
- 大文件顺畅打开（1MB以上）
- 编辑模式保护：禁用手势返回、返回按键、我的页面
- 编辑模式底部按钮（取消、提交修改），不跟随键盘移动
- 取消和提交修改二次确认
- 编辑模式隐藏文件大小和时间行，行高减半
- 提交修改后自动恢复手势返回

### 📄 文件操作
- 上传文件（多选/单选，最后确认上传）
- 下载文件（保存到tmp目录，自动唤醒iOS分享功能）
- 新建文件（创建后直接跳转到编辑状态）
- 创建文件夹
- 重命名文件/文件夹
- 删除文件（多选删除，二次确认）
- 复制文件完整Raw地址
- HTML网页查看器（重压文件菜单）
- 图片显示（PNG等图片格式正常打开）
- 重压文件菜单：编辑文件、重命名、删除（红色字体，二次确认）、HTML预览

### 📝 提交记录
- 查看仓库提交历史
- 显示提交信息、作者头像、作者名、时间、短哈希
- 支持按分支筛选提交
- 下拉刷新
- 滚动加载更多（自动去重）
- 提交详情：提交信息、作者、完整哈希复制、变更统计
- 变更文件列表：文件名、路径、状态图标、新增/删除行数
- 文件Diff视图：行号显示、新增行绿色、删除行红色、变更标记蓝色

### 🐛 Issues功能
- Issues列表（状态切换：开放/已关闭/全部）
- 新建Issue（标题、描述）
- Issue详情：头部信息、描述、评论列表
- 添加评论
- 关闭/重新打开Issue
- 下拉刷新、滚动加载更多

### 🔀 Pull Requests功能
- PR列表（状态切换：开放/已关闭/全部）
- 新建PR（标题、源分支、目标分支、描述）
- PR详情：对话/提交/文件变更三个Tab
- PR评论
- 合并PR
- 下拉刷新、滚动加载更多

### ⚡ Actions功能

- 实时日志流（1秒刷新，只显示日志内容）
- 失败时显示退出码，点击跳转到失败日志

### ⚙️ 仓库设置

### 👤 个人中心

## 快速开始

### 1. 获取 GitHub Token

1. 登录 GitHub 账号
2. 点击右上角头像 → **Settings**
3. 左侧菜单选择 **Developer settings**
4. 选择 **Personal access tokens** → **Tokens (classic)**
5. 点击 **Generate new token** → **Generate new token (classic)**
6. 填写 Note，设置过期时间
7. **勾选权限**：
   - `repo` (完整仓库访问权限，必需)
   - `user` (读取用户信息，必需)
   - `workflow` (Actions工作流操作，可选)
8. 点击 **Generate token**
9. **立即复制保存 Token**（只显示一次）

### 2. 编译运行

#### 使用 Xcode（推荐）

1. 克隆项目到本地
2. 双击 `GitHub.xcodeproj` 打开项目
3. 选择你的开发团队（Signing & Capabilities）
4. 连接 iOS 设备或选择模拟器
5. 按 `Cmd + R` 运行

#### 使用 GitHub Actions 自动构建

1. Push 代码到 GitHub 仓库
2. 进入仓库的 **Actions** 页面
3. 等待 **Build iOS App** 工作流完成
4. 下载构建产物中的 `GitHub.ipa`
5. 使用全能签或第三方签名工具安装

### 3. 使用应用

1. 打开应用，在登录页输入你的 GitHub Token
2. 点击「立即登录」
3. 登录成功后即可浏览仓库、查看和编辑代码

## Token 权限说明

| 权限 | 说明 | 是否必需 |
|------|------|----------|
| `repo` | 完整仓库访问（读写） | ✅ 必需 |
| `repo:status` | 访问提交状态 | 包含在 repo |
| `repo_deployment` | 访问部署状态 | 包含在 repo |
| `public_repo` | 公开仓库访问 | 包含在 repo |
| `user` | 读取用户信息 | ✅ 必需 |
| `read:user` | 读取用户资料 | 包含在 user |
| `workflow` | Actions工作流操作 | ⭕ 可选 |

## 安全说明

- Token 仅存储在设备本地的 Keychain 中
- 不会上传到任何第三方服务器
- 应用卸载后 Token 自动清除
- 建议定期轮换 Token，设置合理的过期时间
- 所有API请求使用官方规范请求头

## CI/CD 流水线

- **分支触发强隔离**：仅main分支触发完整生产流水线；PR和其他分支仅执行编译校验+静态分析
- **精准版本自动化**：三段语义版本（补丁位0~9自动进位），内置单元测试
- **未签名IPA导出**：流水线不做任何代码签名，产物供给全能签使用
- **产物绝对隔离**：IPA仅作为Artifacts存储，严禁提交到Git仓库
- **制品元数据**：自动计算SHA256，生成元数据JSON（版本、commit、构建时间、哈希）
- **标准化日志迭代**：构建成功自动更新README顶部更新日志
- **质量门禁**：编译警告计数门禁，超出阈值直接标记失败
