# 项目文档目录

本目录存放项目的运维文档、配置手册和故障排查指南。

## 文件说明

### repository-setup-guide.md
**仓库环境配置手册**

**功能参数说明：**

| 章节 | 中文释义 | 说明 |
|------|---------|------|
| `目录结构` | 仓库目录结构说明 | 详细说明仓库各目录的用途和规范 |
| `环境要求` | 开发环境要求 | 列出 Xcode、macOS、iOS 部署目标等版本要求 |
| `权限配置` | GitHub 仓库权限配置 | 说明 Workflow 读写权限配置方法 |
| `Secrets配置` | 敏感信息配置 | 说明需要配置的 GitHub Secrets（本项目无需签名相关 Secrets） |
| `分支策略` | 分支管理策略 | 说明 main 分支保护规则和 PR 流程 |

---

### pipeline-operations-guide.md
**流水线运维与故障排查文档**

**功能参数说明：**

| 章节 | 中文释义 | 说明 |
|------|---------|------|
| `流水线架构` | CI/CD 架构说明 | 详细说明生产构建和 PR 校验两条流水线的 Job 编排 |
| `版本逻辑` | 版本进位逻辑说明 | 三段式语义版本（主.次.补丁），补丁位 0~9，自动进位 |
| `单元测试` | 版本脚本单元测试 | 87 个测试用例，覆盖所有边界场景 |
| `常见错误` | 编译错误排查 | 常见 Xcode 编译错误及解决方案 |
| `本地调试` | 脚本本地运行方法 | 版本计算、单元测试、日志更新脚本的本地调试方法 |
| `参数调优` | 构建参数优化指南 | Xcode 编译缓存、依赖缓存、并行构建等优化参数 |

### artifact-guide.md
**制品说明文档**

**功能参数说明：**

| 章节 | 中文释义 | 说明 |
|------|---------|------|
| `制品结构` | IPA 包结构说明 | 未签名 IPA 的目录结构和 Bundle 信息 |
| `SHA256校验` | 哈希校验使用说明 | 如何使用 artifact-metadata.json 中的 SHA256 校验文件完整性 |
| `全能签导入` | 全能签导入注意事项 | IPA 导入全能签进行本地重签名的步骤和注意事项 |
| `元数据说明` | 制品元数据 JSON 说明 | artifact-metadata.json 各字段含义（版本号、commit哈希、构建时间、SHA256、文件名、构建耗时） |
| `生命周期` | 制品生命周期管理 | Actions Artifacts 保留策略和自动清理机制 |

## 文档维护规范

1. 每次新增功能或修改流水线时，必须同步更新对应文档
2. 文档中的参数说明必须包含中文释义
3. 故障排查文档需记录实际遇到的问题和解决方案
4. 文档变更需经过 PR 审核
